# sdk

Runtime-agnostic TypeScript SDK for the Splitly control plane API

A shared package of the splitly workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Splitly control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Splitly web console (per-environment, Workers + Static Assets)
